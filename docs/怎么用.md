# 怎么用（从零到能聊）

这份是「怎么真的用起来」的说明，比 README 细。分三块：电脑这边、网络（Tailscale 那段最要紧）、手机这边。

---

## 一、先弄清两半

| 哪半边 | 是什么 | 在哪 |
| --- | --- | --- |
| 手机 | 鲸笺 App，只负责显示和打字 | 你的手机 |
| 电脑 | 一个后端（DSH 插件），所有消息存在它这里 | 你的电脑，`server/` |

**只装手机那半边跑不起来**：手机里没有一条能说话的线，就是空壳。

---

## 二、电脑这边：把后端立起来

1. 装 DeepSeek Harness（桌面版）
2. 把仓库里的 `server/` 放进插件目录，并建一个链接指向它：

   ```bash
   cd ~/.dsh/profiles/desktop/node_modules
   ln -s /path/to/whaletter/server dsh-whaletter-chat     # Windows 用: mklink /J dsh-whaletter-chat <路径>
   ```

3. 在 `~/.dsh/profiles/desktop/cordis.patch.yml` 末尾加：

   ```yaml
   - insert:
       - id: dsh-whaletter-chat
         name: dsh-whaletter-chat
   ```

4. 重开 DSH。插件第一次启动会在 `server/data-root/config.json` 生成配置：

   ```json
   {
     "访问令牌": "自动生成的一长串",
     "目标会话": "",      // ← 填你要对着聊的那个会话 id
     "手机端口": 8791
   }
   ```

   `目标会话` 怎么拿：浏览器打开 `http://127.0.0.1:8791/api/sessions?token=那串令牌`，
   从返回里挑一个 `id` 填进去。

5. 验证一下后端活着：浏览器打开

   ```
   http://127.0.0.1:8791/api/state?token=你的令牌
   ```

   能看到一串 JSON 就说明它起来了。

## 三、手机和电脑怎么互相看见

手机要连电脑，本质只需要一件事：**手机能访问到电脑的那个端口**。三种情况：

### 情况 A：在同一个 WiFi（最简单，也最快）

电脑上查自己的内网地址（Windows）：

```
ipconfig
```

找 `IPv4 地址` 那一行，一般是 `192.168.x.x` 或 `10.x.x.x`。
手机上填 `192.168.x.x:8791` 就行。

**注意**：不少校园网、酒店 WiFi 开了「设备隔离」，同一 WiFi 也互相看不见。这种就用情况 B。

### 情况 B：不在一起，用 Tailscale（推荐）

Tailscale 干的事：给你的每台设备发一个固定的虚拟地址（`100.x.x.x`），不管你在什么网络，
只要双方都登录了同一个账号，就能互相访问——不用公网 IP，不用改路由器。

**1. 电脑上装 Tailscale**

官网下载安装，登录一个账号（建议用 Google / GitHub / 邮箱注册，注册一次就够）。

**2. 手机上装 Tailscale**

应用商店搜 Tailscale，装好后**登录同一个账号**。

**3. 记下电脑的 Tailscale 地址**

电脑上：

```
tailscale status
```

第一行自己的地址就是，形如 `100.97.16.102`。

**4. 把这个端口放出来（只在需要时做）**

插件默认只监听本机。让 Tailscale 把它转出去：

```bash
tailscale serve --bg --tcp=8791 tcp://127.0.0.1:8791
```

查一下是否生效：`tailscale serve status`，能看到 `8791` 那几行就对了。

**5. 手机上填**：`100.97.16.102:8791`（换成你自己的那个地址）

#### Tailscale 的几个坑，先知道省事

- **手机同时只能挂一个 VPN**。Tailscale 在手机上就是 VPN，你的加速器/梯子也是 VPN，
  两个抢一个位置：开了 Tailscale，梯子就被顶掉，浏览器上不了外网；反过来也一样。
  要聊天就连 Tailscale，要上外网就切回梯子。
- **电脑那边别挂着系统代理去连**。如果电脑的系统代理指向一个已经关掉的端口，浏览器和
  手机上的一些请求都会失败。出问题先看：Windows 设置 → 网络和 Internet → 代理，
  确认「使用代理服务器」是关的，或者指向的端口真的有程序在听。
- **重启后转发会丢**。`tailscale serve` 的配置在重启后可能没了，重跑一次第 4 步。
- **地址是固定的**，不会因为换 WiFi 变化——这就是它比内网地址好用的地方。

### 情况 C：自己有公网 IP，或者有台服务器

那就不用 Tailscale：直接填公网地址；或者用 frp 之类把电脑的 8791 反代到服务器上。

## 四、手机这边：装好、填好、开聊

1. 装 APK（自己编译：`cd android && ./gradlew assembleDebug`，包在
   `android/app/build/outputs/apk/debug/`）
2. 打开 App，第一次会直接落在「设置 → 账号管理 → 改这条」：填地址和令牌，点「存下」
3. 回到消息页，点那条线进去，就能说话了
4. 侧栏（左上角两条线）：表情包、聊天页背景、消息页背景、设置

---

## 五、连不上怎么查（按顺序来）

1. **后端活着吗**：电脑浏览器开 `http://127.0.0.1:8791/api/state?token=...`
2. **网通吗**：手机浏览器开同一个地址（把 127.0.0.1 换成电脑的地址）。
   打不开 = 网络没通，回去检查 Tailscale 是否都登录、是否同一个账号、转发是否还在
3. **令牌对吗**：能打开但提示 401，就是令牌填错了，去 `config.json` 里对一遍
4. **目标会话填了吗**：连上但发消息没回音，多半是 `目标会话` 空着或者 id 不对

## 六、日常会用到的地方

- **改名字**：设置 → 对方的名字（列表里显示的名字会跟着变）- **加一条线**：设置 → 账号管理 → ＋ 加一条线（每个联系人都是一条线）
- **删一条线**：每条线右边的「删」，确认后连它在本机存的消息一起清掉
- **换背景**：侧栏 → 聊天页背景 / 消息页背景，可以各挑各的
- **换头像**：侧栏最上面那个头像，点一下从相册选
- **断网也有记录**：手机本地会留最近两百条，联网自动对账
- **发不出去会排队**：网一回来自己补发
- **后台通知**：安卓上程序被系统冻结就收不到（国产 ROM 尤其明显），
  切出去那一小会儿有效；App 里有「后台常驻」开关，能改善一点，但不是万能

### 「空间」那一页怎么往里贴东西

空间里的内容**不是 App 发的**，是你电脑上的一个文件：

```
server/public/space.json
```

往里加一条（`ts` 是时间戳，毫秒；越新的越靠上、越亮，越旧的越沉、越暗）：

```json
[
  {"ts": 1893456000000, "text": "今天想说的那句话", "img": ""}
]
```

存盘就生效，手机上切到「空间」页下拉一下就能看到，不用重启也不用重新打包。
`img` 留空就行，暂时没做图片。

仓库里自带的那个文件里放了两三条示例，你可以直接改成自己的。

## 七、安全

- 令牌就是钥匙，别贴到公开的地方（截图、仓库、聊天群）
- 默认走的是明文 http。跨公网的话，建议只用 Tailscale 这种加密隧道，
  别直接把 8791 暴露到公网
- 聊天记录都在 `server/data-root/` 里的 `messages.jsonl`，想备份就复制它

## 八、还没做的（这些确实没有，别以为坏了）

按「最可能被问」的顺序排：

| 没做什么 | 现在的状况 | 为什么 |
| --- | --- | --- |
| **后台/锁屏通知** | 只有刚切出去那一小会儿能弹；App 被系统冻结或划掉之后收不到 | 没有系统级推送；国产 ROM 会把后台进程冻住。真要做只有「写原生层定时唤醒」一条路，还没开工 |
| **好友 / 通讯录** | 只能「加一条线 / 删一条线」；没有备注、分组、搜索、头像 | 真正的联系人页还没做 |
| **电脑 → 手机 传文件** | 只能手机发文件到电脑；反过来只能自己开下载链接 | 没做推送文件的入口 |
| **在 App 里发「空间」** | 空间里的内容只能由后端写（`server/public/space.json`），手机只能看 | 只做了读，没做写 |
| **语音消息** | 没有录音、没有播放 | 要接录音库 |
| **已读 / 撤回 / 引用** | 都没有 | —— |
| **群聊** | 一条线就是一对一的，没有群 | —— |
| **端到端加密** | 没有。消息在电脑上是明文，走的是 http（靠 Tailscale 那层加密） | —— |
| **多设备消息同步状态** | 几台手机可以连同一个后端，但「已读」「正在输入」这类状态没有 | —— |
| **表情包商店 / 在线更新表情** | 表情是打包进 App 的，只能按内置那批用 | —— |
| **多语言** | 只有中文 | —— |
| **iOS 版** | 只有 Android。代码是 React Native，理论上能编 iOS，但没试过 | —— |

### 还有几个「有限制」但不算没做的

- **单条消息 8000 字**、**单个文件 12MB**：超过会被拒绝
- **本地只留最近 200 条**：手机上看更早的要等联网去拉
- **别人的实例要靠网络够得着**：对方没装 Tailscale 或者没做转发，你填了地址也进不去
